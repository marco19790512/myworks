# 我的網頁作品集 (My Web Portfolio)

> 匯集 AI 應用研發、互動小遊戲、資安合規工具、商業管理儀表板、品牌識別與視覺藝術創作的整合作品庫。

---

## 📌 專案簡介

本專案收錄由 **Marco 曾** 開發與設計的 **44 件數位專案與創作**，涵蓋多領域實戰應用、演算法與純前端離線安全工具。  
所有作品皆已完成系統化語意命名與類型歸檔，並透過根目錄下的互動式入口頁面 [`index.html`](index.html) 提供流暢的瀏覽、即時檢索、分類篩選與多媒體預覽體驗。

---

## 🚀 快速瀏覽入口

- **本機體驗**：直接以瀏覽器開啟根目錄的 [`index.html`](index.html) 即可暢遊所有專案。
- **線上展示**：可直接於 GitHub 設定中啟用 **GitHub Pages**（選擇 `main` 分支根目錄），即可將作品集發布為線上公開展示站！

## 🌟 重點作品亮點

### 1. 智慧應用與商業分析 (`apps/`)
- **2026 AI 影片製作：Vibe Coding 決策儀表板**：Code-as-Video 程式化影片新典範，深度解析四大框架 (HyperFrames / Remotion / Clipkit / Manim)、OpenMontage 7階段管線與互動式 TCO 成本試算器。
- **注意力魔法大冒險**：注意力喚醒與生命探索應用，支援兒童／大人雙模式切換、能量探測量表、外在微整理與信念宣告。
- **2026 全球 AI Agent 產業研究儀表板**：深入分析 15 大跨產業地圖、商業變現模式與 Top 10 創業機會。
- **微美地圖 (Micro Beauty Map)**：美容體驗社群與生活美容探索平台。
- **神秘星啟塔羅**：結合經典偉特牌義與 AI 深度解牌互動體驗。
- **台灣美業與醫美價格差異分析**：設備買斷資本 (CapEx)、加密耗材 (OpEx) 與療程定價之產業經濟學分析。

### 2. 本地資安合規與實用工具 (`tools/`)
- **企業敏感資料去識別化平台**：100% 瀏覽器純前端本地運算，不聯網、不上傳伺服器，支援 Excel/CSV 多分頁自動欄位感知與去識別化。
- **個資假名化與逆向還原工具**：自訂鹽值加密，保留資料關聯性並支援對照還原。
- **即時氣象觀測站**：串接 Open-Meteo 免費 API，即時提供全台氣象與生活穿著建議。

### 3. 互動遊戲體驗 (`games/`)
- **太鼓達人：和太鼓大作戰**：鍵盤敲擊判定、曲目切換與連擊 Combo 判定。
- **木鱉果大豐收**：Canvas 流暢動畫接果小遊戲。
- **復古文字版電子雞 (Tamagotchi)**：養成模擬、狀態計時與互動樂趣。
